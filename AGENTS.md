# Repository Instructions

## Purpose

This repository packages the Advanced AI Cognitive Framework as a reusable Codex skill.

## Working Rules

- Read `.agents/skills/advanced-ai-cognitive-framework/SKILL.md` before changing the skill.
- Keep `AGENTS.md` concise; place detailed guidance under the skill's `references/` directory.
- Write user-facing documentation in Traditional Chinese unless a file explicitly requires English.
- Do not present assumptions, estimates, or model-generated claims as verified facts.
- For current, legal, medical, financial, security, or policy claims, require external verification and record the source date.
- Preserve the distinction between facts, inferences, assumptions, opinions, unknowns, and recommendations.
- Prefer primary sources and official documentation.
- Never fabricate citations, file paths, commands, test results, or completed actions.

## Change Procedure

1. Inspect the relevant files.
2. State the intended change and affected files.
3. Make the smallest coherent change.
4. Check Markdown headings, links, code fences, and internal consistency.
5. Confirm the skill metadata remains valid.
6. Summarize changed files and any unresolved uncertainty.

## Definition of Done

A documentation change is complete when:

- The workflow is executable by Codex.
- Trigger conditions are clear.
- Outputs have explicit quality criteria.
- High-risk claims include verification requirements.
- Examples match the actual instructions.
- No contradictory rules remain.
